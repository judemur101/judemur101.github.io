# Jude Murray — Portfolio

Personal portfolio site for Jude Murray, B.S. Data Analytics & Statistics (minors in Economics and Data Science), High Point University, May 2027.

Covers quantitative trading tools, SEC EDGAR fundamentals pipelines, Power BI modeling, and statistical/ML projects in Python, R and SQL.

## Structure

- `index.html` — the whole site: HTML, CSS and a small canvas script, no build step
- Fonts load from Google Fonts; there are no other dependencies

## Run locally

Open `index.html` in a browser, or:

```bash
python -m http.server 8000
```

## Deploy

Hosted with GitHub Pages from the `main` branch root.
